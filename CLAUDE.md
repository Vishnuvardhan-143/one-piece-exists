## Claude Code Execution Rules

### Output Management

When working on large projects:

* Prefer creating and modifying files directly instead of printing large code blocks.
* Do not output entire codebase in chat.
* Do not generate more than one major feature in a single response unless explicitly requested.
* Break large tasks into smaller implementation steps.
* Keep responses concise when code has already been written to files.

### Large Project Workflow

For projects with multiple pages, components, or features:

1. Create the folder structure first.
2. Create files incrementally.
3. Implement one feature at a time.
4. Verify functionality before continuing.
5. Avoid generating the entire application in a single response.

### Token Efficiency

To avoid output token limits:

* Write code directly to files whenever possible.
* Summarize file changes instead of printing full file contents.
* Only show complete file contents when explicitly requested.
* Prefer diffs and targeted edits over full rewrites.
* Keep explanations brief and focused on important decisions.
